# ping-pong-game

## Overview
A classic 2D arcade Ping Pong game built to demonstrate clean state management, real-time rendering, and interactive user input controls. This project showcases algorithmic logic for collision detection and game loop synchronization.

## Key Features
* **Real-Time Physics:** Collision detection algorithms managing the ball bouncing off boundaries and player paddles.
* **Dual-Player Controls:** Responsive event listeners capturing keyboard/input movements for smooth gameplay.
* **Score Tracking System:** Automated state updates that track player points and trigger game-over conditions dynamically.

## Technical Stack
* **Language:** html , Javascript, css
